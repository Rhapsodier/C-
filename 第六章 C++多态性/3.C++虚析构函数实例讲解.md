# C++虚析构函数实例讲解

## 什么是虚析构函数

虚析构函数是C++中一个重要的概念，它解决了通过基类指针删除派生类对象时可能出现的内存泄漏问题。当基类的析构函数是虚函数时，通过基类指针删除派生类对象会正确调用派生类的析构函数。

## 为什么需要虚析构函数

### 问题示例

```cpp
#include <iostream>
using namespace std;

class Base {
public:
    Base() {
        cout << "Base构造函数" << endl;
    }
    
    // 非虚析构函数 - 可能导致问题
    ~Base() {
        cout << "Base析构函数" << endl;
    }
};

class Derived : public Base {
public:
    Derived() {
        cout << "Derived构造函数" << endl;
    }
    
    ~Derived() {
        cout << "Derived析构函数" << endl;
    }
};

int main() {
    Base* ptr = new Derived();
    
    // 问题：只调用Base的析构函数，Derived的析构函数不会被调用
    delete ptr;
    
    return 0;
}
```

**输出结果：**
```
Base构造函数
Derived构造函数
Base析构函数
```

**问题分析：** Derived的析构函数没有被调用，如果Derived类中有动态分配的内存，就会造成内存泄漏。

## 虚析构函数的解决方案

### 正确的实现

```cpp
#include <iostream>
using namespace std;

class Base {
public:
    Base() {
        cout << "Base构造函数" << endl;
    }
    
    // 虚析构函数 - 解决问题
    virtual ~Base() {
        cout << "Base析构函数" << endl;
    }
};

class Derived : public Base {
public:
    Derived() {
        cout << "Derived构造函数" << endl;
    }
    
    ~Derived() override {
        cout << "Derived析构函数" << endl;
    }
};

int main() {
    Base* ptr = new Derived();
    
    // 正确：先调用Derived的析构函数，再调用Base的析构函数
    delete ptr;
    
    return 0;
}
```

**输出结果：**
```
Base构造函数
Derived构造函数
Derived析构函数
Base析构函数
```

## 内存泄漏的详细示例

### 没有虚析构函数的情况

```cpp
#include <iostream>
using namespace std;

class Base {
public:
    Base() {
        cout << "Base构造函数" << endl;
    }
    
    ~Base() {
        cout << "Base析构函数" << endl;
    }
};

class Derived : public Base {
private:
    int* data;
    
public:
    Derived() {
        data = new int[100];
        cout << "Derived构造函数 - 分配内存" << endl;
    }
    
    ~Derived() {
        delete[] data;
        cout << "Derived析构函数 - 释放内存" << endl;
    }
};

int main() {
    Base* ptr = new Derived();
    
    // 问题：Derived的析构函数不会被调用，内存泄漏！
    delete ptr;
    
    return 0;
}
```

**问题：** `data`指向的内存永远不会被释放，造成内存泄漏。

### 使用虚析构函数解决

```cpp
#include <iostream>
using namespace std;

class Base {
public:
    Base() {
        cout << "Base构造函数" << endl;
    }
    
    virtual ~Base() {
        cout << "Base析构函数" << endl;
    }
};

class Derived : public Base {
private:
    int* data;
    
public:
    Derived() {
        data = new int[100];
        cout << "Derived构造函数 - 分配内存" << endl;
    }
    
    ~Derived() override {
        delete[] data;
        cout << "Derived析构函数 - 释放内存" << endl;
    }
};

int main() {
    Base* ptr = new Derived();
    
    // 正确：Derived的析构函数被调用，内存被正确释放
    delete ptr;
    
    return 0;
}
```

## 虚析构函数的继承性

### 继承链中的虚析构函数

```cpp
#include <iostream>
using namespace std;

class GrandBase {
public:
    GrandBase() {
        cout << "GrandBase构造函数" << endl;
    }
    
    virtual ~GrandBase() {
        cout << "GrandBase析构函数" << endl;
    }
};

class Base : public GrandBase {
public:
    Base() {
        cout << "Base构造函数" << endl;
    }
    
    virtual ~Base() {
        cout << "Base析构函数" << endl;
    }
};

class Derived : public Base {
public:
    Derived() {
        cout << "Derived构造函数" << endl;
    }
    
    ~Derived() override {
        cout << "Derived析构函数" << endl;
    }
};

int main() {
    GrandBase* ptr = new Derived();
    
    // 析构顺序：Derived -> Base -> GrandBase
    delete ptr;
    
    return 0;
}
```

**输出结果：**
```
GrandBase构造函数
Base构造函数
Derived构造函数
Derived析构函数
Base析构函数
GrandBase析构函数
```

## 抽象类的虚析构函数

### 纯虚析构函数

```cpp
#include <iostream>
using namespace std;

class AbstractBase {
public:
    AbstractBase() {
        cout << "AbstractBase构造函数" << endl;
    }
    
    // 纯虚析构函数
    virtual ~AbstractBase() = 0;
    
    // 纯虚函数
    virtual void pureFunc() = 0;
};

// 纯虚析构函数必须提供实现
AbstractBase::~AbstractBase() {
    cout << "AbstractBase析构函数" << endl;
}

class Concrete : public AbstractBase {
public:
    Concrete() {
        cout << "Concrete构造函数" << endl;
    }
    
    ~Concrete() override {
        cout << "Concrete析构函数" << endl;
    }
    
    void pureFunc() override {
        cout << "Concrete::pureFunc()" << endl;
    }
};

int main() {
    AbstractBase* ptr = new Concrete();
    ptr->pureFunc();
    delete ptr;
    
    return 0;
}
```

## 虚析构函数的性能考虑

### 虚函数表的开销

```cpp
#include <iostream>
using namespace std;

class Base {
public:
    Base() {}
    
    // 虚析构函数会增加虚函数表开销
    virtual ~Base() {}
    
    // 其他虚函数
    virtual void func1() {}
    virtual void func2() {}
};

class Derived : public Base {
public:
    Derived() {}
    
    ~Derived() override {}
    
    void func1() override {}
    void func2() override {}
};

int main() {
    // 虚函数会增加对象大小（虚函数表指针）
    cout << "Base大小: " << sizeof(Base) << " 字节" << endl;
    cout << "Derived大小: " << sizeof(Derived) << " 字节" << endl;
    
    return 0;
}
```

## 最佳实践

### 1. 基类析构函数应该是虚函数

```cpp
class Base {
public:
    virtual ~Base() = default;  // 使用default关键字
};
```

### 2. 如果类有虚函数，析构函数也应该是虚函数

```cpp
class Base {
public:
    virtual void func() = 0;
    virtual ~Base() = default;  // 必须的
};
```

### 3. 析构函数应该是public的

```cpp
class Base {
public:
    virtual ~Base() = default;  // public访问权限
};
```

## 总结

虚析构函数的重要性：

1. **防止内存泄漏**：确保派生类析构函数被正确调用
2. **正确的析构顺序**：先析构派生类，再析构基类
3. **多态性支持**：通过基类指针正确析构派生类对象
4. **设计原则**：如果类设计为继承，析构函数应该是虚函数

**记住：** 当类被设计为基类时，析构函数应该是虚函数！
