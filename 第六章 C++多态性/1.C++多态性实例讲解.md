# C++多态性实例讲解

## 什么是多态性

多态性是面向对象程序设计的重要特性之一，指同样的方法被不同对象执行时会有不同的执行效果。多态性可以分为两种：

- **编译时多态**：编译时就确定了具体的操作过程
- **运行时多态**：在程序运行过程中才确定的操作过程

## 编译时多态示例

### 函数重载

```cpp
#include <iostream>
using namespace std;

class Calculator {
public:
    // 函数重载 - 编译时多态
    int add(int a, int b) {
        return a + b;
    }
    
    double add(double a, double b) {
        return a + b;
    }
    
    int add(int a, int b, int c) {
        return a + b + c;
    }
};

int main() {
    Calculator calc;
    
    cout << "add(5, 3) = " << calc.add(5, 3) << endl;
    cout << "add(5.5, 3.2) = " << calc.add(5.5, 3.2) << endl;
    cout << "add(5, 3, 2) = " << calc.add(5, 3, 2) << endl;
    
    return 0;
}
```

### 运算符重载

```cpp
#include <iostream>
using namespace std;

class Complex {
private:
    double real, imag;
    
public:
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}
    
    // 运算符重载 - 编译时多态
    Complex operator+(const Complex& c) const {
        return Complex(real + c.real, imag + c.imag);
    }
    
    void display() const {
        cout << real << " + " << imag << "i" << endl;
    }
};

int main() {
    Complex c1(3, 4);
    Complex c2(1, 2);
    Complex c3 = c1 + c2;  // 使用重载的+运算符
    
    cout << "c1: ";
    c1.display();
    cout << "c2: ";
    c2.display();
    cout << "c1 + c2: ";
    c3.display();
    
    return 0;
}
```

## 运行时多态示例

### 虚函数实现多态

```cpp
#include <iostream>
using namespace std;

class Shape {
public:
    virtual void draw() {
        cout << "绘制形状" << endl;
    }
    
    virtual ~Shape() {}
};

class Circle : public Shape {
public:
    void draw() override {
        cout << "绘制圆形" << endl;
    }
};

class Rectangle : public Shape {
public:
    void draw() override {
        cout << "绘制矩形" << endl;
    }
};

int main() {
    Shape* shapes[3];
    shapes[0] = new Shape();
    shapes[1] = new Circle();
    shapes[2] = new Rectangle();
    
    // 运行时多态 - 根据实际对象类型调用相应的方法
    for (int i = 0; i < 3; i++) {
        shapes[i]->draw();
    }
    
    // 清理内存
    for (int i = 0; i < 3; i++) {
        delete shapes[i];
    }
    
    return 0;
}
```

## 多态性的优势

1. **代码复用**：基类指针可以指向派生类对象
2. **扩展性**：添加新的派生类不需要修改现有代码
3. **维护性**：统一的接口，便于维护和修改

## 总结

多态性是C++面向对象编程的核心概念，通过编译时多态和运行时多态，我们可以编写更加灵活、可扩展的代码。编译时多态主要通过函数重载和运算符重载实现，而运行时多态则通过虚函数和继承实现。
