# 第六章 C++多态性

## 📚 章节概述

C++多态性这一章主要介绍C++多态性、C++虚函数、C++虚析构函数以及C++纯虚函数与抽象类。多态性是面向对象程序设计的重要特性之一，从字面意思上可以简单理解就是：多种形态，多个样子。其实本质意思也是这样，在面向对象程序设计中，指同样的方法被不同对象执行时会有不同的执行效果。

### 🔧 核心概念

- **多态性(Polymorphism)**：同样的方法被不同对象执行时会有不同的执行效果
- **编译时多态**：编译的时候就确定了具体的操作过程
- **运行时多态**：在程序运行过程中才确定的操作过程
- **联编(Binding)**：确定操作过程的过程，也称为绑定
- **虚函数**：实现运行时多态的关键机制
- **抽象类**：包含纯虚函数的类，不能实例化
