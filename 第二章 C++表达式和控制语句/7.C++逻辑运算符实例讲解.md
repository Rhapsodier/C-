## C++逻辑运算符实例讲解

C++中的逻辑运算符包括 `&&`、`||`、`!` 三种，分别表示逻辑与、逻辑或、逻辑非，下面分别讲解。

### 1. 逻辑与 `&&`

逻辑与是一个双目运算符，使用时`&&`的两边各一个表达式，如果运算符的左右两边的表达式都为真，表达式整体才为真，否则即为假。

例如：

```cpp
5 && 6      // 真
1 && -1     // 真
1 < 2 && 5 // 真
3-3 && 5   // 假
10-- && 0  // 假
```

### 2. 逻辑或 `||`

逻辑或运算符也是一个双目运算符，使用时要求两边各一个表达式，如果运算符左右两边的表达式只要有一个为真，那么逻辑或表达式的整体就为真，否则都为假。

例如：

```cpp
3-3 || 5   // 真
0 || 5-5   // 假
```

### 3. 逻辑非 `!`

逻辑非是一个单目运算符，它表示取反的意思，放在表达式的左边，如`!a`，即原先为真的表达式取反之后变为假，原先为假的表达式取反之后变为真。

例如：

```cpp
!0        // 结果为1
!(2>1)    // 结果为0
```

以上，希望大家加强理解，在实际的学习工作中，往往是关系运算符、算数运算符、逻辑运算符等运算符和变量组合在一起的复合表达式，因此要熟练规则。

如以下代码，大家觉得这两个表达式值是多少呢？

```cpp
#include<iostream>
using namespace std;
int main()
{
    int a = 10;
    int b = 20;
    int c = 30;
    int d, e;
    d = !c > (b - a) && (c - b) > (b - a);
    e = (b - a) || (c - b) && !(c - b - a);
    return 0;
}
```
