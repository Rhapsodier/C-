## C++关系运算符实例讲解

C++中的关系运算符包括 `>`, `<`, `>=`, `<=`, `!=`, `==` 六种。顾名思义，关系运算符需要两个操作数做比较，如谁大谁小，谁和谁相等不相等。关系运算符表达式的结果就是非0即1的结果，请大家理解这句话。

下面我们通过举例子的形式让大家理解这六个运算符，如：

```cpp
10 > 5;    // 10大于5，很明显成立，是真
2 >= 2;    // 2大于或者等于2，也成立，是真
3 != 1;    // 3不等于1，的确成立，是真
5 == 5;    // 5确实等于5，成立，为真
```

以上四个表达式，请大家理解它们的用法，然后尝试用代码打印它们的值。

参考代码：

```cpp
#include<iostream>
using namespace std;
int main()
{
    cout << (10 > 5) << endl;
    cout << (2 >= 2) << endl;
    cout << (3 != 1) << endl;
    cout << (5 == 5) << endl;
    return 0;
}
```
