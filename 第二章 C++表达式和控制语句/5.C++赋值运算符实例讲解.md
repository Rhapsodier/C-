## C++赋值运算符=实例讲解

=是C语言和C++中的赋值运算符，用于变量、数组等的赋值使用，操作方向是从右至左，如：

```cpp
#include<iostream>
using namespace std;
int main()
{
    int a = 10; // 定义变量a，并且将10作为初始化值赋给a
    int b;
    b = a; // 将a的值赋值给b
    return 0;
}
```

赋值运算符的特点就是从右往左运算，大家可以通过注释，重新理解赋值运算符。从今天开始要更改之前对=的看法，它并非数学上的等于，而是赋值，且正确的读法也是从右往左读，如b=a应读为“将a赋值给b”。
