# 第二章 C++表达式和控制语句

## 📚 章节概述

C++表达式和控制语句这一章主要介绍C++中的数据类型、运算符和控制结构。C++中的数据类型，常用的有 int、char、float、double，分别表示整型、字符型、单精度和双精度类型，包括它们的扩展类型与C语言中用法都一致。运算符和控制语句的相关知识语法与C语言相比基本没有发生变化。

### 🔧 核心内容

- **数据类型**：基本数据类型及其扩展类型
- **运算符**：算术、关系、逻辑、赋值、自增自减运算符
- **控制结构**：选择结构（if、switch）和循环结构（while、do-while、for）
