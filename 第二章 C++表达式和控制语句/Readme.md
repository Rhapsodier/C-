# C++表达式和控制语句

C++表达式和控制语句这一章主要介绍C++中的数据类型、C++算数运算符、C++bool类型、C++自增++和自减--运算符、C++赋值运算符、C++关系运算符、C++逻辑运算符、C++if选择结构、C++switch选择结构、C++while循环结构、C++do while循环以及C++for循环。C++中的数据类型，常用的有 int、char、float、double，分别表示整型、字符型、单精度和双精度类型，包括它们的扩展类型与C语言中用法都一致。运算符和控制语句的相关知识语法与C语言相比基本没有发生变化。
