# C++函数重载实例讲解

## 函数重载的概念

在实际的代码编写当中，有时候对于同一个功能函数，可能处理的对象类型不同，则需要重新实现一遍这个函数，这样下去就显得代码更加繁多，C++为了解决这一问题，而支持函数重载来解决这个问题。

## 传统解决方案的问题

比如一个算术求和的问题，需要自定义一个函数，用来接收传入数据并求和，但作为独立的一个模块，如何知道调用方传入什么类型的数据呢？可能是整型数据，当然也可能是浮点类型的数据，还可能是一个整数一个浮点型（还不知道哪一个是整型，哪一个是浮点型）。

传统的做法是为各种类型的形参都定义一个函数：
- `Add_int_int()`: 两个int类型
- `Add_double_double()`: 两个double类型
- `Add_int_double()`: 第一个int第二个double
- `Add_double_int()`: 第一个double第二个int

这种方式显然会导致代码混乱且难以维护。

## C++函数重载解决方案

C++中函数重载很好地解决了这个问题。函数重载即两个或以上的函数，函数名相同，但形参类型或个数不同，编译器根据调用方传入的参数的类型和个数，自动选择最适合的一个函数来进行绑定调用，自动实现选择。

### 实例代码

```cpp
#include<iostream>
using namespace std;

int add(int a,int b)
{
    cout<<"(int ,int)\t";
    return a+b;
}

double add(double a,double b)
{
    cout<<"(doble ,double)\t";
    return a+b;
}

double add(double a,int b)
{
    cout<<"(double ,int)\t";
    return a+b;
}

double add(int a,double b)
{
    cout<<"(int ,double)\t";
    return a+b;
}

int main()
{
    cout<<add(2,3)<<endl;        // 调用 add(int, int)
    cout<<add(2.9,15.3)<<endl;   // 调用 add(double, double)
    cout<<add(10,9.9)<<endl;     // 调用 add(int, double)
    cout<<add(11.5,5)<<endl;     // 调用 add(double, int)
    return 0;
}
```

### 代码说明
请大家仔细阅读代码，为了确认哪个函数得到执行，我们在函数内部加了一句cout的输出语句，用来区分哪个函数得到调用。

### 输出结果
```
(int ,int)    5
(doble ,double)    18.2
(int ,double)    19.9
(double ,int)    16.5
```
