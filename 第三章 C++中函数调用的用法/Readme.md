# 第三章 C++中函数调用的用法

## 📚 章节概述

C++函数调用与重载内联这一章主要介绍C++中函数调用的用法、C++带默认形参值的函数、C++函数重载、C++函数模板以及C++内联函数inline。C++中函数调用的方法与C语言并无区别，依旧是在调用方函数中执行函数调用语句来实现函数调用。

### 🔧 核心内容

- **函数调用**：C++函数调用的基本方法和语法
- **默认参数**：带默认形参值的函数定义和使用
- **函数重载**：同名函数的不同参数版本
- **函数模板**：泛型编程的基础
- **内联函数**：提高程序执行效率的inline函数
