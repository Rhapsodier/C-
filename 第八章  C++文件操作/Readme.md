# 第八章 C++文件操作

## 📚 章节概述

C++文件操作这一章主要介绍C++读写文件操作、C++如何打开文件、C++读文件操作、C++写文件操作以及C++如何关闭文件。C++中对于文件的操作，主要是用过以下几个类来支持的，它们分别是：

### 🔧 核心类介绍

- **ofstream**：写操作（输出）的文件类（由ostream引申而来）
- **ifstream**：读操作（输入）的文件类（由istream引申而来）  
- **fstream**：可同时读写操作的文件类（由iostream引申而来）
