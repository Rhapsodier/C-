# C++如何打开文件

## 打开文件概述

要想对文件继续读写，首先完成第一步打开，那么C++如何打开文件？这里需要用到在fstream类中的成员函数open()实现打开文件的操作，open函数是istream、ostream、fstream的成员函数，它的原型如下：

```cpp
void open(const char *filename, ios::openmode mode);
```

## 参数说明

- **第一个参数filename**：表示要打开的文件路径
- **第二个参数mode**：表示打开文件的模式

## 文件打开模式

| 参数 | 作用 |
|------|------|
| ios::in | 为输入(读)而打开文件 |
| ios::out | 为输出(写)而打开文件 |
| ios::ate | 初始位置：文件尾 |
| ios::app | 所有输出附加在文件末尾 |
| ios::trunc | 如果文件已存在则先删除该文件 |
| ios::binary | 二进制方式 |

## 组合使用模式

除此以外，还可以用过'|'或运算符将多个参数进行组合使用，如：

```cpp
ofstream out;  
out.open("dotcpp.txt", ios::out|ios::binary);  //以二进制模式打开，进行写数据
```
