# C++写文件操作

## 写文件概述

接上篇，对于要用C++进行写文件，则可以用ofstream或fstream类型，依次经过打开、写数据、关闭三个步骤完成。请看如下实例：

## 代码实现

```cpp
#include <fstream>
#include <iostream>
using namespace std;

int main()
{
    char data[100] = "Welcome to dotcpp";
    ofstream file;
    file.open("d:\\dotcpp.dat");
    file << data;
    file.close();
    return 0;
}
```

## 运行效果

## 重要提醒

大家主要注意文件读写的运算符`<<`和`>>`的区别，其实是运算符的重载实现，大家不要弄反方向！

- **`<<`**：用于输出（写文件）
- **`>>`**：用于输入（读文件）
