# C++如何关闭文件

## 关闭文件概述

对于前两步，打开和读写大家熟练使用之后，那么最后一步关闭文件也就容易多了。在结束相关操作之后，只需要在最后调用close()成员函数即可，即会断开文件与程序的关联，结束操作。

## close()函数说明

该close函数是ifstream、ofstream、fstream的成员函数，在使用时用打开的文件对象通过`.`直接调用即可。

## 完整示例

通过学习前面的读写操作，可以注意最后一步关闭文件的语句，如：

```cpp
#include <fstream>
#include <iostream>
using namespace std;

int main()
{
    char data[100] = "Welcome to dotcpp";
    ofstream file;
    file.open("d:\\dotcpp.dat");
    file << data;
    file.close();  //调用close函数，关闭文件操作
    return 0;
}
```

## 重要提醒

- 关闭文件是一个良好的编程习惯
- 及时关闭文件可以释放系统资源
- 避免文件句柄泄露
