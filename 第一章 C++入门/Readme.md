## C++概述
C++是一种计算机高级程序设计语言，由C语言扩展升级而产生。特点包括：
- 既支持C语言的过程化程序设计
- 支持以抽象数据类型为特点的基于对象的程序设计
- 支持以继承和多态为特点的面向对象的程序设计
- 兼顾面向对象和基于过程的程序设计
- 注重实用性的同时提高大规模程序的编程质量
- 增强程序设计语言的问题描述能力
