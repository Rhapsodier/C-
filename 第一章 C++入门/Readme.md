# 第一章 C++入门

## 📚 章节概述

C++入门这一章主要介绍C++基础概念、学习方法和第一个程序。C++是一种计算机高级程序设计语言，由C语言扩展升级而产生，具有强大的面向对象编程能力。

### 🔧 核心特点

- **多范式支持**：既支持C语言的过程化程序设计，又支持面向对象程序设计
- **抽象数据类型**：支持以抽象数据类型为特点的基于对象的程序设计
- **继承和多态**：支持以继承和多态为特点的面向对象的程序设计
- **高质量编程**：注重实用性的同时提高大规模程序的编程质量
- **问题描述能力**：增强程序设计语言的问题描述能力

3. **举一反三**：尝试修改示例代码，加深理解
4. **注意细节**：特别注意语法差异和编程规范
