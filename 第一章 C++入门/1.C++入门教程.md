# C++入门教程

## 课程简介
本套《C++入门教程》由站长黄老师亲自撰写和设计，具有以下特点：

### 适用对象
- 面向有C语言基础的同学  
  🔗 *（未学习过C语言的同学可[https://www.dotcpp.com/course/c/](#)先学习C语言）*

### 开发环境
- 主推编译器：**CodeBlocks**  
  🔗 使用教程： [https://www.dotcpp.com/wp/818.html](#)*
- 兼容编译器：VC6等其他C++编译器(适合新手)

作者建议自己配置一下C++工具链，很有必要。至于具体怎么配置请自行搜索。
- 作者环境：VSCode + Vim

## 课程特色
| 特色 | 说明 |
|------|------|
| 理论+实践 | 每章配套实时评测作业系统 |
| 即时验证 | 内置在线编译器（右侧可唤出） |
| 项目驱动 | 最终结课设计综合实践 |
| 目标明确 | 聚焦面向对象程序设计精髓 |
