# 第七章 C++异常处理

## 📚 章节概述

C++异常处理这一章主要介绍C++异常的概念、C++异常处理机制try catch以及C++标准异常exception处理类。程序的错误通常包括：语法错误、逻辑错误、运行异常。通常情况下，虽然无法避免程序异常错误，但是却可以进行预见性的处理来避免程序崩溃，从而保障程序的健壮性，这种行为我们称之为异常处理。

### 🔧 核心概念

- **异常(Exception)**：程序运行时发生的错误或意外情况
- **异常处理**：预见性处理来避免程序崩溃，保障程序健壮性
- **try-catch**：C++异常处理的基本语法结构
- **throw**：抛出异常的关键字
- **标准异常类**：C++标准库提供的异常处理类
- **程序健壮性**：程序在异常情况下的稳定性和可靠性
