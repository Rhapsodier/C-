# C++对象的建立和使用

## 引言
回顾上节课的核心概念：
> "类是对象的抽象和概括，而对象是类的具体和实例"

## 1. 对象的创建与使用

### 1.1 基本概念
- 类是一种自定义数据类型
- 对象是类的实例化
- 创建对象就是实例化一个类

### 1.2 对象的使用方法
对象的使用方式与结构体类似，通过`.`运算符访问成员。

示例代码：
```cpp
Student A;               // 创建对象
A.num = 101;            // 访问成员变量
strcpy(A.name,"dotcpp"); // 设置字符串
A.score = 100;          // 设置成绩
A.print();              // 调用成员函数上节课的“类是对象的抽象和概括，而对象是类的具体和实例”这句话吗？学会类的定义之后，下一步就是对象的创建和使用了！
```



对象的创建：

类就是包含函数的结构体，是一种自定义数据类型，用它定义出来变量，就是对象，这就是所谓的“对象是类的具体和实例”，定义了一个这个类的对象，也可以说实例化了一个对象，就是这个意思！



而对象的使用，和结构体的使用也一样，都是主要访问里面的成员，也都是用过.的方式来访问，如：
```
Student A;
A.num = 101;
strcpy(A.name,"dotcpp");
A.score = 100;
A.print();
```

### 1.3 访问控制注意事项
1. **public成员**
   - 可以直接通过对象访问
   - 没有访问限制

2. **private成员**
   - 不能直接通过对象访问
   - 尝试直接访问会导致编译错误

### 1.4 封装与接口
为了实现数据保护和封装，我们通常：
1. 将成员变量声明为`private`
2. 提供`public`的访问方法（getter/setter）
3. 通过这些公共方法间接控制私有成员

> 这些公共方法被称为类的外部接口，是实现封装的重要手段。

## 2. 对象指针

### 2.1 基本概念
- 对象在内存中占据连续空间
- 可以创建指向对象的指针
- 对象指针存储对象的内存地址

### 2.2 对象指针的定义
语法格式：
```cpp
类名 *指针名;
```


### 2.3 对象指针的使用
需要注意：
- 仅定义指针并不会创建对象
- 不会调用构造函数
- 需要将指针指向一个已存在的对象

示例代码：
```cpp
Student *p;        // 定义对象指针
Student A;         // 创建对象
p = &A;           // 指针指向对象
p->print();       // 通过指针访问成员
```

### 2.4 对象指针的优势
- 通过地址访问对象
- 避免对象复制
- 减少内存开销
- 提高程序效率
- 特别适合在函数参数传递时使用

## 3. 对象引用

### 3.1 基本概念
引用是C++的一个重要特性：
- 本质是对象的别名
- 与原对象共享同一内存空间
- 通过地址实现

### 3.2 引用的定义与初始化
```cpp
Student A;         // 创建对象
Student &Aq = A;   // 创建引用
```
### 3.3 引用的注意事项

1. **类型匹配**
   - 引用类型必须与被引用对象类型相同
   - 不支持不同类型间的引用

2. **初始化要求**
   - 定义引用时必须初始化
   - 例外：作为函数返回值或形参时可以不初始化

3. **内存特性**
   - 不创建新对象
   - 不调用构造函数
   - 仅创建别名

### 3.4 引用的使用
```cpp
Student A;         // 创建对象
Student &Aq = A;   // 创建引用
Aq.print();       // 通过引用访问成员
```

### 3.5 引用的优点
1. **内存效率**
   - 与指针一样高效
   - 不需要额外的内存开销

2. **使用便捷**
   - 语法与对象本身一致
   - 使用`.`运算符访问成员
   - 作为函数参数时不需要`&`符号

3. **代码清晰**
   - 比指针更直观
   - 更容易理解和维护
   - 减少了出错的可能
