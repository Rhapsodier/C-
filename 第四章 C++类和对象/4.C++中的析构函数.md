# C++中的析构函数(Destructor)

## 1. 析构函数概述

### 1.1 析构函数的定义
- 与类名同名
- 名字前加波浪线`~`
- 没有返回值
- 在对象销毁时自动调用
- 主要用于清理工作

### 1.2 与构造函数的共同点
- 函数名与类名相同
- 没有返回值
- 都是公开类型
- 系统会自动生成默认版本

### 1.3 与构造函数的区别
- 析构函数不能重载
- 一个类只能有一个析构函数
- 析构函数可以是虚函数
- 名字前必须加`~`符号

## 2. 析构函数示例

## 2. 析构函数示例

### 2.1 Student类的实现
```cpp
#include <iostream>
#include <cstring>
using namespace std;

class Student {
private:
    int num;            // 学号
    char name[100];     // 名字
    int score;          // 成绩
    
public:
    Student(int n, char *str, int s);    // 构造函数
    ~Student();                          // 析构函数
    int print();                         // 打印信息
    int Set(int n, char *str, int s);    // 设置信息
};

// 构造函数实现
Student::Student(int n, char *str, int s) {
    num = n;
    strcpy(name, str);
    score = s;
    cout << num << " " << name << " " << score << " ";
    cout << "Constructor" << endl;
}

// 析构函数实现
Student::~Student() {
    cout << num << " " << name << " " << score << " ";
    cout << "destructor" << endl;
}

// 打印函数实现
int Student::print() {
    cout << num << " " << name << " " << score << endl;
    return 0;
}

// Set函数实现
int Student::Set(int n, char *str, int s) {
    num = n;
    strcpy(name, str);
    score = s;
    return 0;
}
```

### 2.2 析构函数的使用
```cpp
int main() {
    Student A(100, "dot", 11);    // 创建第一个对象
    Student B(101, "cpp", 12);    // 创建第二个对象
    return 0;                     // 程序结束，对象被销毁
}
```

## 3. 重要说明

### 3.1 析构顺序
对象的析构顺序与构造顺序相反，这是因为：
- 局部对象存储在栈区
- 栈区遵循"先进后出"(LIFO)原则
- 最后创建的对象最先被销毁

### 3.2 执行结果分析
运行上述代码，输出结果将显示：
1. 首先创建对象A（调用构造函数）
2. 然后创建对象B（调用构造函数）
3. 程序结束时，先销毁对象B（调用析构函数）
4. 最后销毁对象A（调用析构函数）
