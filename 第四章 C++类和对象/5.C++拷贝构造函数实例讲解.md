# C++拷贝构造函数实例详解

## 1. 拷贝构造函数概述

### 1.1 定义与特点
- 与类名同名的特殊构造函数
- 形参是本类对象的引用类型
- 用于通过已有对象初始化新对象
- 也称为复制构造函数(Copy Constructor)

### 1.2 默认行为
- 系统会自动生成默认拷贝构造函数
- 默认版本进行成员间的简单赋值
- 可以被自定义的版本替换

## 2. 示例实现

### 2.1 Circle类定义
```cpp
#include <iostream>
using namespace std;
#define PI 3.1415

class Circle {
private:
    double R;    // 半径
    
public:
    Circle(double R);         // 普通构造函数
    Circle(Circle &A);        // 拷贝构造函数
    double area();            // 计算面积
    double girth();           // 计算周长
};

// 普通构造函数实现
Circle::Circle(double R) {
    cout << "Constructor" << endl;
    this->R = R;
}

// 拷贝构造函数实现
Circle::Circle(Circle &A) {
    cout << "Copy Constructor" << endl;
    this->R = A.R;
}

// 计算面积
double Circle::area() {
    return PI * R * R;
}

// 计算周长
double Circle::girth() {
    return 2 * PI * R;
}
```
### 2.2 拷贝构造函数的使用
```cpp
int main() {
    Circle A(5);      // 使用普通构造函数
    Circle B(A);      // 使用拷贝构造函数
    return 0;
}
```

### 2.3 执行过程分析
1. 对象A的创建：
   - 调用普通构造函数
   - 传入参数值5
   - 输出"Constructor"

2. 对象B的创建：
   - 调用拷贝构造函数
   - 以对象A作为参数
   - 输出"Copy Constructor"

## 3. 重要说明

### 3.1 为什么需要自定义拷贝构造函数
尽管C++会自动生成默认的拷贝构造函数，但在以下情况下需要自定义：
- 当类包含指针成员时
- 需要深拷贝而不是简单赋值时
- 需要在对象复制时执行特定操作时

### 3.2 默认拷贝构造函数的局限
- 仅执行简单的成员赋值（浅拷贝）
- 对于复杂的数据结构可能会有问题
- 不能满足特殊的初始化需求
