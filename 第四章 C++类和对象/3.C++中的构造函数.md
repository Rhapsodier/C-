# C++中的构造函数(Constructor)

## 1. 构造函数概述

### 1.1 构造函数的特点
- 函数名与类名相同
- 没有返回值
- 创建对象时自动调用
- 主要用于对象的初始化

### 1.2 默认构造函数
- 如果没有定义构造函数，系统会自动生成
- 默认构造函数的函数体为空
- 不执行任何初始化操作

### 1.3 自定义构造函数
当定义了自己的构造函数后：
- 系统不再生成默认构造函数
- 根据参数匹配选择合适的构造函数调用

## 2. 构造函数示例

### 2.1 Student类的实现

```cpp
#include <iostream>
#include <cstring>
using namespace std;

class Student {
private:
    int num;            // 学号
    char name[100];     // 名字
    int score;          // 成绩
    
public:
    Student(int n, char *str, int s);    // 构造函数
    int print();                         // 打印信息
    int Set(int n, char *str, int s);    // 设置信息
};

// 构造函数的实现
Student::Student(int n, char *str, int s) {
    num = n;
    strcpy(name, str);
    score = s;
    cout << "Constructor" << endl;
}

// 打印函数的实现
int Student::print() {
    cout << num << " " << name << " " << score;
    return 0;
}

// Set函数的实现
int Student::Set(int n, char *str, int s) {
    num = n;
    strcpy(name, str);
    score = s;
    return 0;
}
```
### 2.2 构造函数的使用
```cpp
int main() {
    Student A(100, "dotcpp", 11);    // 创建对象时自动调用构造函数
    A.print();                        // 打印对象信息
    return 0;
}
```

## 3. 注意事项

### 3.1 构造函数的调用时机
- 在创建对象时自动调用
- 可以在定义对象时直接传入初始值

### 3.2 构造函数的重载
- 可以定义多个构造函数
- 系统根据参数匹配选择合适的构造函数
- 如果找不到匹配的构造函数会报错

### 3.3 重要提示
> 当类中定义了带参数的构造函数后，系统不再提供默认构造函数。此时如果要创建对象，必须提供相应的参数，否则会编译错误。
