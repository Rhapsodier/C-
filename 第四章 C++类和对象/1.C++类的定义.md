# C++类的定义

## 1. 类与对象的概念

什么是类？什么是对象？对于面向对象的C++语言学习，类和对象的理解是整个语言学习中核心的基础。

通俗的理解：
- **类**就是一个模子，是一个变量类型
- **对象**就是这个类型定义出来的具体的变量

例如在`int a;`这个语句中：
- `int`对应类（注意：这只是一个比喻，实际上`int`是C++的内置类型，不是真正的类）
- `a`就对应对象

### 核心概念
> 类是对象的抽象和概括，而对象是类的具体和实例。

## 2. C++类的基本结构

C++中的类本质上是一个包含函数的结构体！它包含两种成员：
1. **成员变量**：类似C语言结构体中的基本变量
2. **成员方法**：类中定义的函数

### 2.1 类的定义方式

使用`class`关键字定义类，下面是一个学生类的示例：

```cpp
class Student
{
public:
    int num;            // 学号
    char name[100];     // 姓名
    int score;          // 成绩
    
    int print()         // 成员方法
    {
        cout << num << " " << name << " " << score;
        return 0;
    }
};
```

### 2.2 访问控制

类中的`public`关键字是控制成员访问权限的存取控制属性，C++提供三种访问级别：

1. **private**（私有）
   - 仅能被该类的成员访问
   - 外界不能访问
   - 最严格的访问级别

2. **protected**（保护）
   - 类内成员可以访问
   - 子类可以访问
   - 比private更开放一些

3. **public**（公有）
   - 可以被该类的任何对象访问
   - 完全公开的数据

> 注意：类定义后面需要加分号，这是很容易被忽略的细节！

### 2.3 成员函数的两种定义方式

#### 2.3.1 在类内定义（内联方式）
如上面的示例所示，直接在类定义中编写函数实现。

#### 2.3.2 在类外定义（分离方式）
当类中的成员函数较多时，为了提高代码的可读性，可以采用在类外定义成员函数的方式：

```cpp
class Student
{
public:
    int num;            // 学号
    char name[100];     // 名字
    int score;          // 成绩
    int print();        // 类内只声明函数原型
};

// 在类外定义成员函数
int Student::print()    // 使用作用域限定符::
{
    cout << num << " " << name << " " << score;
    return 0;
}
```

#### 关键点说明：
1. 在类外定义成员函数时，需要使用`类名::函数名`的形式
2. 作用域限定符`::`用来指明该函数属于哪个类
3. 函数的参数列表和返回类型需要与类内声明保持一致

### 选择建议
- 对于简单的函数，可以直接在类内定义
- 对于较复杂的函数，建议在类外定义，以提高代码的可读性
- 根据具体项目的规范和需求选择合适的方式

> 建议：尝试这两种方式编写代码，体会它们的优缺点，选择适合自己的方式。
